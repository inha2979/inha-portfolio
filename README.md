# Inha Kim Portfolio

## Files
- `index.html`: main portfolio page
- `style.css`: all design and responsive styling
- `script.js`: scroll animation and current year
- `assets/`: resume and project images

## Before publishing
1. Replace `your-email@example.com`.
2. Replace LinkedIn and GitHub links.
3. Add your resume as `assets/Inha_Kim_Resume.pdf`.
4. Replace the dashboard screenshot placeholder with a real image.
5. Review project wording and add exact results where available.

## GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload all files in this folder.
3. Go to Settings → Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Select `main` and `/root`.
6. Your site will appear at `https://YOURUSERNAME.github.io`.
